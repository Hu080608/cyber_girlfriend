数据

          
所有数据默认存在当前浏览器 localStorage。换浏览器、清理缓存会丢失；可开启下面的加密 Gist 同步，或使用导出备份。

          

          
GitHub Pages 只负责提供静态文件；不会保存任何聊天或 API Key。开启 Gist 同步后，数据会加密后保存到你的未列出（secret）Gist。

          
若浏览器报 CORS 错误，说明 DeepSeek/SiliconFlow 不允许网页直接跨域调用。你需要在设置里填写一个允许 CORS 的 API 中转地址，或自己部署一个很小的 Cloudflare Worker 代理。

        

        

          
跨设备同步：GitHub Gist 加密备份

          
人设、配置、记忆、聊天记录会先用你的同步密码加密，再保存到一个未列出（secret）GitHub Gist。换设备后输入同样的 Token、Gist ID 和密码即可恢复。
